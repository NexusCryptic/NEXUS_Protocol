## Purpose

This document is the chronological spine for the Living System. It records only evidence that can be anchored to an accessible repository, commit, file object, or an explicitly marked incoming artifact. Missing historical blocks remain gaps; they are not reconstructed as facts.

## Evidence states

- **VERIFIED** — directly observed through GitHub connector data and anchored to a repository object or commit.
- **CORRELATED** — strongly related to the canonical system but requires additional lineage or authorship confirmation.
- **INCOMING** — supplied by the Architect but not yet present in the accessible evidence set.
- **EXTERNAL** — useful research/upstream material; never promoted to native GAIA/NEXUS provenance without an explicit derivation record.
